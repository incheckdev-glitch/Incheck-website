# InCheck 360 Website

Production marketing website for InCheck 360.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Custom responsive CSS
- No required runtime secrets

## Main routes

- /
- /platform
- /food-safety
- /smart-detectors
- /industries
- /product/[slug]
- /solutions/[slug]
- /resources
- /about
- /contact
- /book-demo

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

The project is designed for deployment on Vercel or any compatible Node.js hosting environment.
